## 为什么要写博客

写博客不是为了给别人看，而是为了**给自己一个交代**。

学了一个新技术，当时觉得懂了，过两周就忘得七七八八。但如果写下来，写的过程就是重新理解的过程。

> 如果你没法把一个东西讲清楚，说明你还没真正理解它。

## 这个博客怎么搭的

技术栈很简单：

- **Next.js 16** — 页面框架
- **Tailwind CSS v4** — 样式
- **MDX** — 用 Markdown 写文章，还能嵌入组件

整个站点没有数据库，文章就是文件夹里的 `.mdx` 文件。

## 一段代码示例

```typescript
function greet(name: string): string {
  return `你好，${name}！欢迎来到我的博客。`;
}

console.log(greet("世界"));
```
